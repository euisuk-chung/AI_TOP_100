# AI_TOP_100 Preliminary Round: Choonsik's Gourmet Menu Analysis

Source: https://brunch.co.kr/@andkakao/323

### **Problem Description**

Analyze the menu board image to extract menu names and prices, categorize them, and calculate the average price.

Choonsik, a gourmet, is traveling around the country in search of delicious restaurants. Choonsik takes pictures of the menu board at every restaurant he visits and records them in his gourmet notebook. However, as the number of visited restaurants increased, it became difficult to organize the menu board photos by hand.

So Choonsik decided to create an AI system that automatically analyzes the menu board photos. This system recognizes the text in the menu board image to extract the menu name and price, classifies the menu by category (Meals, Sides, Beverages, Alcohol), and even calculates the average price for each category.

Help Choonsik complete the gourmet notebook!

### **Notes and References**

The currency unit is KRW (won), and the exchange rate is not considered.

If the same menu name appears multiple times, treat it as a separate menu.

If there is no price, exclude it from the calculation.
