# Question
에이전트가 새로운 지시사항에 대해 일반화하지 못합니다.

# Answer
LLM Agent

# Explanation
**문제 상황 (The Problem):**
구식 "챗봇"이나 스크립트는 엄격한 if-then 규칙을 따릅니다. "환불 봇"에게 "이 물건이 고장 나서 반품하고 싶어"라고 하면 작동합니다. 하지만 "이걸 샀는데 산산조각 났어, 어떻게 해야 해?"라고 물으면, 규칙 기반 봇은 "산산조각(shattered)"에 대한 규칙이 없으면 실패할 수 있습니다.

**해결책: LLM Agent**
LLM Agent는 대규모 언어 모델(Large Language Model)을 두뇌로 사용합니다.
- **Reasoning (추론)**: "산산조각"이 "고장"과 "반품"을 의미한다는 것을 이해합니다.
- **Adaptability (적응성)**: 상식을 사용하여 이전에 본 적 없는 지시사항을 처리할 수 있습니다.
- **Tool Use (도구 사용)**: 단순한 키워드 매칭이 아니라 이해를 바탕으로 *어떤* 규칙이나 도구를 적용할지 결정합니다.

**실제 기업 사례 (Real Enterprise Example):**
**Tidio Lyro**: Tidio의 고객 지원 에이전트인 Lyro는 LLM(Claude 등)을 사용하여 고객 문의의 최대 70%를 자동으로 해결합니다. 정확한 키워드가 필요했던 구식 챗봇과 달리, Lyro는 주문 상태나 제품 세부 정보에 대한 복잡하고 서술적인 질문을 이해하고 회사의 지원 문서를 추론하여 자연스럽고 정확한 답변을 제공할 수 있습니다.
