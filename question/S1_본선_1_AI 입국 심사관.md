# AI_TOP_100 본선 문제 : AI 입국 심사관

Source: [final_immigration](source/q6)

### **문제 설명**

당신은 가상의 국가 아틀란티스의 입국 심사관입니다. 국경을 넘으려는 사람들의 서류를 검사하고 입국 허가 여부를 판단하는 역할을 맡고 있습니다. 최근 위조 서류를 이용한 입국 시도가 빈번하게 적발되고 있습니다.

당신은 25개의 상세 규정을 확인하고, 7가지 입국 서류(여권, 비자, 입국 신고서 등)를 꼼꼼히 대조하여 누락, 위조되었거나 유효하지 않은 정보를 제출하는 사람을 정확히 식별해야 합니다.

제출된 서류 데이터의 누락, 불일치, 유효기간 등 기본 요건을 검증하고, 25개 상세 입국 규정을 적용하여 모든 항목의 준수 여부를 교차 확인하세요. 규칙 위반이 없으면 '승인', 있으면 첫 위반 사유와 함께 '거부' 판정을 내려서 입국 신청자를 정확하게 심사하세요.

### **참고 및 유의사항**

모든 입국 승인/거부 판정은 오직 inspection\_rules.txt에 명시된 25개 규칙에만 근거해야 합니다.

모든 날짜 관련 유효성 판단의 기준 시점은 데이터에 명시된 심사일(inspection\_date: 2025-11-22)입니다.

여러 거부 사유에 해당하는 경우, 가장 낮은 번호의 규칙을 reason으로 제출해야 합니다.

지정된 JSON 형식을 준수하여 결과를 제출하세요.

### Q. 30명의 입국 신청자에 대한 심사 결과를 아래 형식에 맞춰 제출해 주세요.

제출 형식: 아래 스키마를 만족하는 단일 JSON array

- id: 심사 ID (예: applicant\_001)

- answer: 승인/거부 판정 (Approve 또는 Deny, 대소문자 준수)

- reason: Deny인 경우 거부 사유 번호 (숫자)

> ```json  
> [  
>  {  
>  "id": "applicant\_001",  
>  "answer": "Approve"  
>  },  
>  {  
>  "id": "applicant\_002",   
>  "answer": "Deny",  
>  "reason": 3  
>  }  
> ]  
> ```
