# AI_TOP_100 본선 문제 : 몽타주를 그려라

### **문제 설명**

세상에 단 하나뿐인 '황금 초콜릿' 트로피가 사라졌습니다. 범인을 본 목격자는 이렇게 말했습니다.

"30대 정도의 남성에 눈이 크고 아몬드 모양의 깊고 진한 눈, 길고 곧게 뻗었지만 좌우 폭은 넓지 않은 코, 부드러운 미소를 가졌으며 양 옆으로 길지 않은 입술"

현장에 있던 또 다른 AI 목격자 '카오'는 범인의 얼굴을 완벽하게 기억하고 있지만, 스스로 설명하는 기능은 없습니다. 대신 당신이 제출한 몽타주를 보고, 그것이 실제 얼굴과 얼마나 유사한지 수치로 피드백 합니다. AI 목격자 '카오'가 주는 단서를 분석하여 진짜 범인의 얼굴을 복원해야 합니다.

목격자의 묘사를 분석하여 생성형 AI를 위한 최적의 프롬프트를 설계하고 몽타주를 생성한 후, 생성한 몽타주를 API에 제출하여 유사도 점수와 부위별 피드백을 받으세요. 피드백을 해석하고 몽타주를 수정하는 과정을 반복하여 범인의 얼굴을 복원하세요.

### **참고 및 유의사항**

API 제출은 1분당 1회의 rate limit이 있습니다.

제출하는 이미지는 1024x1024 해상도를 유지해야 합니다.

제출하는 이미지는 PNG/JPEG 형식이어야 합니다.

제출하는 이미지 크기는 10MB를 이하여야 합니다.

동일한 이미지(파일 해시 기준)를 반복 제출할 경우 평가되지 않습니다.

---

### Q. 제출된 몽타주 중 최고 유사도를 기록한 이미지가 최종 결과물로 평가됩니다.

API 호출 이력에는 최신 제출한 4건만 표시됩니다.

각 호출 이력에는 현재까지 제출한 몽타주의 최고 유사도도 함께 노출됩니다.
