# 모범 답안: Q1. 고대 유적의 비밀

## 분석
이 문제는 석판에 새겨진 난독화된 C 코드를 제시합니다.
목표는 코드를 해석하고 출력을 예측하는 것입니다.

## 풀이

### Q1. 프로그래밍 언어
**정답**: **2. C**
**근거**: 문제 설명에서 `main.c`와 `gcc`를 명시적으로 언급하고 있으며, 이는 C 프로그래밍의 표준입니다. 코드 문법(`#include <stdio.h>`, `void`, `char*`, `printf`)도 C 언어의 특징입니다.

### Q2. 입력 `1q2w3e4r`에 대한 출력
**정답**: (코드 실행 필요)
**방법**:
1.  이미지에서 코드를 `main.c`로 옮겨 적습니다.
2.  컴파일: `gcc -w main.c -o main`
3.  실행: `./main`
4.  입력: `1q2w3e4r`
5.  출력을 확인합니다.

*참고: 유사한 CTF 문제들을 바탕으로, 이 코드는 단순 치환 암호 또는 XOR 암호를 수행할 가능성이 높습니다. 정확한 코드 텍스트 없이는 출력을 결정할 수 없습니다.*

### Q3. 입력 `STOP`에 대한 출력
**정답**: (코드 실행 필요)
**방법**: Q2와 동일하나, 입력으로 `STOP`을 사용합니다.

## 샘플 코드 구조 (가설)
```c
#include <stdio.h>

int main() {
    char input[100];
    scanf("%s", input);
    // ... 난독화된 로직 ...
    printf("RESULT");
    return 0;
}
```
