# 모범 답안: Q3. The Age of AI: 영상 팩트 체크

## 출제 의도

### 문제 패턴

**P1. 분석 및 정의 (Insight)** - 정답이 없는 복합 데이터 속에서 의미 있는 '문제'나 '기회'를 스스로 정의하고 발견

### 핵심 측정 역량

1. **영상 정보 추출 능력**: 긴 다큐멘터리에서 특정 사실을 정확히 찾아내는 능력
2. **멀티모달 검증**: 시각, 청각 정보를 종합하여 사실 관계 확인
3. **명시적 검증 유도**: 구체적인 수치, 이름, 장소 등 검증 가능한 정답 요구

### 왜 '딸깍'으로 풀리지 않는가?

- AI에게 "이 영상에서 X를 찾아줘"라고 요청해도 **영상 전체를 직접 분석하기 어려움**
- 다큐멘터리가 여러 에피소드로 구성되어 있어 **어디서 정보를 찾을지 판단 필요**
- 세부 사항(음료 종류, 정확한 시간, 마커 개수)은 **사람이 직접 영상을 보고 확인**해야 함
- 검색으로 찾은 정보가 실제 영상 내용과 일치하는지 **교차 검증 필수**

### 난이도 구조

- **Q1-Q2 (Medium)**: 인터뷰 장면에서 특정 사실 확인 - 집중해서 시청 필요
- **Q3 (Easy)**: 숫자 정보 - 검색으로도 확인 가능
- **Q4-Q5 (Medium)**: 등장인물/장소 식별 - 영상 맥락 이해 필요
- **Q6 (Hard)**: 프레임 단위 분석 - 직접 세어야 함 (킬러 문항)
- **Q7 (Medium)**: 복합 사실 판별 - 여러 정보 종합 필요

## 권장 접근법

### 1단계: 사람의 분석

- YouTube에서 "The Age of AI" 시리즈 전체 구조 파악
- 각 에피소드 제목과 주제 매핑
- 문제에서 요구하는 정보가 어느 에피소드에 있을지 예측

### 2단계: AI와의 협업

```text
프롬프트 예시:
"'The Age of AI' 다큐멘터리 시리즈에 대해 알려줘.
각 에피소드의 제목과 주요 내용, 등장인물을 정리해줘.
특히 다음 키워드가 등장하는 에피소드를 찾아줘:
- Soul Machines / 얼굴 시뮬레이션
- Tim Shaw / Project Euphonia
- Austin Dillon / NASCAR 피트스톱
- TuSimple / 자율주행 트럭"
```

### 3단계: 사람의 검증

1. AI가 제공한 에피소드 정보를 바탕으로 **해당 부분 직접 시청**
2. 구체적인 수치(피트스톱 시간, 마커 개수)는 **프레임 단위로 확인**
3. 불확실한 정보는 **여러 소스로 교차 검증**

## 풀이 가이드

### Q1. 킹콩/아바타 얼굴 시뮬레이션 제작자의 음료

**접근법**: "Love, art and stories" 에피소드에서 Mark Sagar(Soul Machines)의 인터뷰 장면을 찾아 확인

**예상 정답**: **4. 따뜻한 허브차** (또는 인터뷰에서 보이는 특정 음료)

### Q2. 팀 쇼의 첫 문장

**접근법**: "Healed through A.I." 에피소드에서 Tim Shaw가 Project Euphonia를 통해 처음 말하는 장면 확인

**예상 정답**: **"I love you"** 또는 가족에게 하는 감동적인 인사

### Q3. 오스틴 딜런 피트스톱 시간

**접근법**: "Saving the world one algorithm at a time" 에피소드에서 RCR 팀의 AI 최적화 피트스톱 기록 확인

**정답**: **8.85** (초)

### Q4. Bobo 배우의 과거 직업

**접근법**: 해당 캐릭터가 등장하는 에피소드에서 배우 정보 확인 후 검색

**예상 정답**: **1. 프로 레슬러** 또는 **5. 댄서**

### Q5. "로봇이 내 일자리를 빼앗을까?"의 장소들

**접근법**: 해당 에피소드에서 TuSimple 자율주행 트럭 테스트 장소 확인

**예상 정답**:
- **2. 롱비치 공항** (캘리포니아 항만 지역)
- **5. TuSimple 본사, 애리조나**

### Q6. 마커 수 (코 + 눈 + 눈썹)

**접근법**: "Love, art and stories" 에피소드의 모션 캡처 장면에서 직접 프레임을 멈추고 세기

**추정 범위**: 약 30-40개
- 눈썹: 눈썹당 약 5개 = 10개
- 눈: 눈꺼풀당 약 4개 = 16개
- 코: 약 4-6개

### Q7. "Healing through AI"의 사실들

**접근법**: 에피소드 전체를 시청하며 각 선택지의 사실 여부 확인

**참인 진술들**:
- **4. 연구는 음성 인식과 합성을 다룬다.** (Project Euphonia의 핵심 기술)
- **5. 아이스 버킷 챌린지가 도움이 되었다.** (ALS 연구 기금 모금과 연결)

## 핵심 교훈

> "영상 콘텐츠에서 특정 사실을 찾는 것은 **AI의 검색 능력**과 **사람의 직접 확인**이 모두 필요하다. AI는 어디를 봐야 하는지 가이드해주지만, **정확한 정보는 사람이 직접 눈으로 확인**해야 한다."

이 문제는 멀티모달 정보 처리에서 AI의 한계와 인간 검증의 중요성을 보여줍니다. 특히 숫자 세기, 정확한 문장 확인 등은 **사람의 꼼꼼한 확인**이 필수입니다.
