# 모범 답안: Q2. 고대 유적의 비밀

## 출제 의도

### 문제 패턴

**P2. 구현 및 자동화 (Action)** - 정의된 문제를 해결하기 위해 AI 솔루션을 실제 작동하는 코드나 워크플로로 구현

### 핵심 측정 역량

1. **이미지에서 코드 추출 능력**: AI의 OCR/비전 기능을 활용하여 이미지 속 난독화된 코드를 정확히 추출
2. **코드 해석 및 실행 능력**: 난독화된 C 코드를 분석하고 실제로 실행하여 결과를 검증
3. **Human-in-the-loop 검증**: AI가 추출한 코드의 정확성을 사람이 직접 컴파일/실행하여 검증

### 왜 '딸깍'으로 풀리지 않는가?

- 이미지 속 코드는 **난독화(Obfuscated)** 되어 있어 AI가 정확히 인식하기 어려움
- 코드의 미세한 문자 오류(예: `0`과 `O`, `1`과 `l`)가 결과에 큰 영향을 미침
- **반드시 코드를 실행해봐야** 정답을 확인할 수 있음 (AI의 추론만으로는 부정확)

---

## 권장 접근법

### 1단계: 사람의 분석

- 문제에서 주어진 힌트 파악: `main.c`, `gcc -w` 등의 키워드
- 이미지 속 코드의 대략적인 구조 파악 (변수명, 함수 구조)

### 2단계: AI와의 협업

```text
프롬프트 예시:
"이 이미지에서 C 코드를 정확히 추출해줘.
난독화된 코드이므로 특수문자, 숫자, 알파벳을 정확히 구분해서 추출해줘.
특히 0과 O, 1과 l을 주의해서 구분해줘."
```

### 3단계: 사람의 검증

1. AI가 추출한 코드를 `main.c` 파일로 저장
2. `gcc -w main.c -o main` 으로 컴파일
3. 컴파일 에러 발생 시 → AI와 함께 코드 수정
4. `./main` 실행 후 입력값 테스트
5. 결과 확인 및 정답 제출

### Q1. 프로그래밍 언어 식별

**접근법**: 문제에서 주어진 힌트(`main.c`, `gcc`)와 코드 문법을 분석하여 프로그래밍 언어를 식별합니다.

**가이드**:

1. 문제 설명에서 파일명 `main.c`와 컴파일러 `gcc` 확인
2. 이미지 속 코드에서 C 언어 특징 확인: `#include <stdio.h>`, `void`, `char*`, `printf`
3. 다른 언어의 가능성 배제

**분석 결과**:

| 힌트 | 근거 |
|------|------|
| main.c | C 언어 소스 파일 확장자 |
| gcc | GNU C Compiler |
| #include <stdio.h> | C 표준 라이브러리 헤더 |

**정답**: **2. C**

### Q2. 입력 `1q2w3e4r`에 대한 출력

**접근법**: 이미지에서 코드를 추출하고, 컴파일 후 실행하여 출력을 확인합니다.

**가이드**:

1. AI를 활용하여 이미지에서 C 코드 추출
2. 추출된 코드를 `main.c`로 저장
3. 컴파일: `gcc -w main.c -o main`
4. 실행: `./main`
5. 입력: `1q2w3e4r`
6. 출력 결과 확인

**코드 실행 과정**:

```bash
$ gcc -w main.c -o main
$ ./main
1q2w3e4r
RWETQSDR
```

**주의사항**:

- AI가 추출한 코드에 OCR 오류가 있을 수 있음
- 컴파일 에러 발생 시 AI에게 에러 메시지 공유하고 수정 요청
- `0`과 `O`, `1`과 `l`, `5`와 `S` 등 혼동 주의

**정답**: **RWETQSDR**

---

### Q3. 입력 `STOP`에 대한 출력

**접근법**: Q2와 동일한 프로세스로 입력값만 `STOP`으로 변경하여 실행합니다.

**가이드**:

1. Q2에서 컴파일한 실행 파일 사용
2. 실행: `./main`
3. 입력: `STOP`
4. 출력 결과 확인

**코드 실행 과정**:

```bash
$ ./main
STOP
KAKAO2025
```

**힌트 해석**: "멈추어야 비로소 보이리라"

- `STOP`이라는 입력은 문제의 수수께끼와 연결됨
- 코드가 특정 입력(`STOP`)에 대해 숨겨진 메시지를 출력하도록 설계됨

**정답**: **KAKAO2025**

## 핵심 교훈

> "AI가 이미지에서 코드를 추출해줄 수 있지만, 그 결과가 정확한지는 **직접 실행해봐야만** 알 수 있다."

이 문제는 AI의 비전 능력과 코드 분석 능력을 활용하되, **최종 검증은 사람이 직접 수행**해야 하는 Human-in-the-loop의 핵심을 보여줍니다.
