# 모범 답안: Q6. 인수인계

## 분석
**목표**: 인수인계 문서 작성 (프로젝트 개요, 아키텍처, API, 트러블슈팅).
**상황**: 핵심 모듈 개발자가 1주일 후 퇴사 예정.

## 샘플 답변

### Q1. 프로젝트 개요
**프로젝트명**: AI 기반 고객 분석 모듈
**설명**: 이 모듈은 여러 채널(웹, 모바일, 고객지원)에서 고객 상호작용 데이터를 수집하고 NLP 모델을 적용하여 감정과 의도를 추출합니다. 처리된 데이터는 CRM 시스템에 공급되어 실시간 개인화 마케팅과 지원을 가능하게 합니다. 목표는 선제적 참여를 통해 고객 유지율을 15% 향상시키는 것입니다.

### Q3. API 문서 (로그인)
**엔드포인트**: `POST /api/v1/auth/login`
**설명**: 사용자를 인증하고 JWT 토큰을 반환합니다.

**요청 본문**:
```json
{
  "email": "user@example.com",
  "password": "secure_password_123"
}
```

**응답 (200 OK)**:
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsIn...",
  "expires_in": 3600,
  "user": {
    "id": "user_123",
    "role": "admin"
  }
}
```

### Q4. 트러블슈팅
**문제**: `처리 워커` 높은 지연시간 / 타임아웃.
**원인**: 데이터 볼륨의 갑작스러운 급증으로 인한 Kafka 컨슈머 지연, 또는 AI 모델 서버의 GPU 메모리 고갈.
**해결방법**:
1. Grafana에서 Kafka 컨슈머 지연을 확인합니다.
2. 지연이 높으면, `처리 워커` 레플리카를 스케일 업합니다 (Kubernetes HPA).
3. GPU OOM이면, `config.yaml`의 배치 크기 설정을 확인하고 줄입니다 (기본값: 32 -> 16).
