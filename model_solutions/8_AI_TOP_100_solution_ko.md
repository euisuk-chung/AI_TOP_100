# 모범 답안: Q8. 인수인계 자료 작성

## 출제 의도

### 문제 패턴

**P3. 소통 및 설득 (Persuasion)** - 협업, 리더십, 프레젠테이션 등 목표가 있는 커뮤니케이션 및 문서 작성

### 핵심 측정 역량

1. **기술 문서 작성 능력**: 복잡한 시스템을 명확하게 설명하는 문서 작성
2. **구조화 능력**: 프로젝트 개요, 아키텍처, API, 트러블슈팅을 체계적으로 정리
3. **독자 고려**: 인수인계 받는 사람의 관점에서 필요한 정보 우선순위 결정
4. **체계적 검증 유도**: 문서의 완성도와 실용성 평가

### 왜 '딸깍'으로 풀리지 않는가?

- "인수인계 문서 써줘"라고 하면 **일반적인 템플릿**만 제공됨
- 실제 프로젝트의 **구체적인 맥락과 히스토리**를 AI가 모름
- 트러블슈팅 가이드는 **실제 경험에서 나온 노하우**가 필요
- 팀 내 **암묵지(tacit knowledge)**를 명시화하는 것은 사람만 가능

### 난이도 구조

- **Q1 (Easy)**: 프로젝트 개요 - 기본적인 설명
- **Q2 (Medium)**: 시스템 아키텍처 - 구조적 사고 필요
- **Q3 (Medium)**: API 문서 - 표준 형식 따르기
- **Q4 (Hard)**: 트러블슈팅 - 실무 경험 기반 (킬러 문항)

---

## 권장 접근법

### 1단계: 사람의 분석

- 프로젝트의 핵심 기능과 비즈니스 목표 정리
- 아키텍처의 주요 컴포넌트와 데이터 흐름 파악
- 자주 발생하는 문제와 해결 방법 정리
- 인수인계 받는 사람이 가장 먼저 알아야 할 것 우선순위 결정

### 2단계: AI와의 협업

```text
프롬프트 예시:
"다음 정보를 바탕으로 인수인계 문서를 작성해줘:

프로젝트: AI 기반 고객 분석 모듈
주요 기능: 고객 상호작용 데이터 수집, NLP 감정 분석, CRM 연동
기술 스택: Python, Kafka, PostgreSQL, Redis, Kubernetes
팀 구성: 백엔드 3명, ML 2명, 인프라 1명

다음 섹션별로 작성해줘:
1. 프로젝트 개요 (목적, 범위, 이해관계자)
2. 시스템 아키텍처 (컴포넌트 다이어그램 포함)
3. API 문서 (주요 엔드포인트)
4. 트러블슈팅 가이드 (자주 발생하는 문제와 해결법)"
```

### 3단계: 사람의 검증

1. 생성된 문서를 **실제 시스템과 대조**하여 정확성 확인
2. **새로운 팀원 관점**에서 이해하기 어려운 부분 보완
3. **빠진 중요 정보**(환경 변수, 배포 절차 등) 추가
4. **실제 트러블슈팅 경험**으로 가이드 보강

### Q1. AutoFlow 교육 장소

**접근법**: 워크스페이스 데이터(캘린더, 메일, 메모 등)에서 "AutoFlow 교육" 관련 일정을 검색하여 장소 정보를 추출합니다.

**가이드**:

1. 캘린더 데이터에서 "AutoFlow" 키워드 검색
2. 교육 일정의 장소(location) 필드 확인
3. 메일이나 메모에서 교육 안내 내용 교차 확인

**정답**: **3. 3층 대회의실**

### Q2. 대학 리크루팅 컨택 완료 대학 수

**접근법**: 워크스페이스 데이터에서 리크루팅 관련 문서나 스프레드시트를 찾아 컨택 상태가 "완료"인 대학 수를 집계합니다.

**가이드**:

1. 메일, 메모, 또는 문서에서 "리크루팅", "대학", "컨택" 키워드 검색
2. 각 대학별 컨택 상태 확인 (완료/진행중/미시작)
3. "완료" 상태인 대학 수 집계

**정답**: **7** (숫자로 입력)

### Q3. 2025년 8월 1일 시작이 아닌 사항

**접근법**: 각 선택지의 시작일을 워크스페이스 데이터에서 확인하여 2025년 8월 1일이 아닌 것을 모두 선택합니다.

**가이드**:

1. 각 항목별 관련 문서/메일/메모 검색
2. 시행일/시작일 확인
3. 2025년 8월 1일이 **아닌** 항목 선별

| 항목 | 시작일 | 8월 1일 여부 |
|------|--------|--------------|
| 출장 식비 1일 5만원으로 상향 | 2025-07-01 | X |
| 출장 숙박비 1일 15만원으로 상향 | 2025-08-01 | O |
| OmegaERP 도입 | 2025-08-01 | O |
| 법인카드 월 한도 500만원으로 상향 | 2025-09-01 | X |
| 하계 인턴십 시작 | 2025-08-01 | O |

**정답**: **1, 4** (출장 식비 상향, 법인카드 월 한도 상향)

### Q4. 완성된 인수인계 문서 제출

**접근법**: `template.md`의 목차와 형식을 정확히 따르면서, 워크스페이스 데이터에서 추출한 정보로 인수인계 문서를 완성합니다.

**가이드**:

1. **데이터 수집**: 모든 워크스페이스 파일 분석
   - 메일: 진행 중인 업무, 연락처, 마감일
   - 캘린더: 예정된 회의, 교육, 일정
   - 메모: 업무 노하우, 주의사항
   - 책상 사진: 물리적 자료, 접근 권한 정보

2. **template.md 구조 준수**: 목차, 테이블 컬럼명, 리스트 항목 정확히 따름

3. **기준일 적용**: 2025년 7월 21일 시점 (이미 지난 일정 제외)

4. **사실 기반 작성**: 데이터에 없는 내용은 추측 금지

**정답 예시**:

```markdown
# 인수인계 문서

작성자: 홍지은
작성일: 2025-07-21

## 1. 진행 중인 프로젝트

| 프로젝트명 | 담당자 | 현재 상태 | 마감일 | 비고 |
|------------|--------|-----------|--------|------|
| AutoFlow 도입 | 홍지은 | 교육 예정 | 2025-08-15 | 3층 대회의실 |
| 하계 인턴십 | HR팀 협업 | 준비 중 | 2025-08-01 | 인턴 5명 |
| OmegaERP 마이그레이션 | IT팀 협업 | 진행 중 | 2025-08-01 | 테스트 완료 |

## 2. 주요 연락처

| 이름 | 소속 | 연락처 | 담당 업무 |
|------|------|--------|-----------|
| 김팀장 | 기획팀 | kim@company.com | 프로젝트 승인 |
| 이대리 | IT팀 | lee@company.com | 시스템 지원 |

## 3. 예정된 일정

| 일자 | 일정 | 장소 | 참석자 |
|------|------|------|--------|
| 2025-07-25 | 주간 회의 | 4층 회의실 | 팀 전원 |
| 2025-08-01 | AutoFlow 교육 | 3층 대회의실 | 홍지은 외 |

## 4. 주의사항 및 노하우

- 법인카드 사용 시 영수증 즉시 제출 필요
- 출장 신청은 최소 3일 전 승인 필요
- OmegaERP 접속 시 VPN 필수

## 5. 미결 사항

| 항목 | 내용 | 우선순위 | 담당자 확인 필요 |
|------|------|----------|------------------|
| 대학 리크루팅 | 나머지 대학 컨택 진행 | 높음 | HR팀 |
```

**정답**: 제공된 워크스페이스 데이터를 분석하여 `template.md` 형식에 맞게 완성된 인수인계 문서를 제출합니다. 실제 정답은 데이터 파일의 구체적 내용에 따라 달라집니다.

## 핵심 교훈

> "인수인계 문서는 **AI가 틀을 잡아주고**, **사람이 실제 경험으로 채워야** 한다. 특히 트러블슈팅 가이드는 **직접 겪어본 문제**와 **해결 노하우**가 담겨야 가치가 있다."

이 문제는 기술 문서 작성에서 AI의 구조화 능력과 사람의 도메인 지식이 어떻게 협업해야 하는지를 보여줍니다. **좋은 문서는 읽는 사람의 관점**에서 작성되어야 합니다.
