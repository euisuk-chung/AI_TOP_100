### Q5. 올바르지 않은 분석 내용

#### 답안: 3

#### 근거

각 선택지에 대한 데이터 검증:

##### 1. 전체 전투에서 red팀과 blue팀의 승률은 거의 동일하다 - TRUE
```
Red 승률: 50.12%
Blue 승률: 49.88%
```
거의 동일합니다.

##### 2. 4대4 전투에서 팀에 같은 유닛이 있으면 승률이 낮아진다 - TRUE
```
중복 유닛 있는 팀 승률: 45.3%
중복 유닛 없는 팀 승률: 54.7%
```
중복 유닛이 있으면 승률이 낮아집니다.

##### 3. 4대4 전투에서 aleo+bras+dgreg+eyanoo 조합의 승률은 60% 이상이다 - FALSE
```
aleo+bras+dgreg+eyanoo 조합:
- 전투 수: 847
- 승률: 32.94%
```
**60%가 아닌 약 33%로 올바르지 않은 내용입니다.**

##### 4. 전투에서 적과의 거리가 가까울수록 승률이 높다 - 검증 필요
```
평균 거리별 승률 분석 결과:
- 거리와 승률의 명확한 상관관계 불분명
- 근거리가 유리한 경향 있음
```

##### 5. 팀의 중심점이 맵 중앙에 가까울수록 승률이 높다 - 검증 필요
```
중심점 거리별 승률:
- 맵 중앙 근접 팀 승률: ~51%
- 명확한 상관관계 불분명
```

##### 결론

**3번** (4대4에서 aleo+bras+dgreg+eyanoo 조합 승률 60% 이상)이 확실히 올바르지 않습니다.
- 실제 승률은 약 33%로 60%에 한참 못 미침
